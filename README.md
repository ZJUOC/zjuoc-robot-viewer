# ZJUOC 水下机器人三维展示

基于 Next.js、React 和 Three.js 的独立网页，无需登录或 API 密钥。

## 运行

需要 Node.js 22 或更高版本。

```sh
npm ci
npm run dev
```

打开 http://localhost:3000/robot-viewer 。生产运行：`npm run build` 后执行 `npm start`。

## 功能与操作

- 展示/运动模式切换；斜置舵机、旋转桨叶和喷流粒子。
- 按机器人纵向长度 40 cm 换算的 3 m × 5 m 水池，暂设深度 1.5 m。
- WASD：随视角平移；Shift：上浮；Ctrl：下潜；J/K：左转/右转。
- 当前移动速度为初版的 4 倍，控制按下和释放均有 1 秒延迟。
- 鼠标左键旋转视角、中键平移、滚轮缩放、右键选择部件。
- 手机支持单指旋转、双指缩放/平移及触屏运动按钮。
- 信息面板可隐藏；桌面端可拖动；提供水池全景与复位视角。

模型为根据参考图重建的演示模型，不是工程 CAD 或真实水动力仿真。当前机体运动为简化运动学，未按四推进器推力分配求解。

本目录仅包含机器人展示页，不包含面试系统、人员资料、参考图片、密钥或其他工作区内容。
