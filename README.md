# ZJUOC 水下机器人三维展示

基于 Next.js、React 和 Three.js 的独立网页，无需登录或 API 密钥。

## 运行

需要 Node.js 22 或更高版本。

```sh
npm ci
npm run dev
```

打开 http://localhost:3000/robot-viewer 。生产运行：`npm run build` 后执行 `npm start`。

## 功能与操作

- 展示/运动模式切换；斜置舵机按视觉伺服规则转向，桨叶旋转并带喷流粒子。
- 按机器人纵向长度 40 cm 换算的 3 m × 5 m 水池，暂设深度 1.5 m。
- WASD：随视角平移；Shift：上浮；Ctrl：下潜；J/K：左转/右转。
- 运动模式显示实时按键盘；可用「1 秒延迟」开关切换延迟，默认开启。
- 水平运动时机体向行进侧倾斜约 5–8°，并叠加小幅水波动摇。
- 信息面板显示机体中心位置与实际速度（水池近端左下角为原点）。
- 水池中有取球赛道：三道门、起点、目标球；运动模式会检测门框碰撞。
- 靠近彩球上方后按 L 吸附/放下（一次一颗）。
- 运动模式使用第三人称跟随相机（按机体航向，不受水波倾斜影响）。
- 鼠标左键旋转视角、中键平移、滚轮缩放、右键选择部件。
- 手机支持单指旋转、双指缩放/平移及触屏运动按钮。
- 桌面端可拖动信息面板；提供水池全景与复位视角。

模型为根据参考图重建的演示模型，不是工程 CAD 或真实水动力仿真。当前机体运动为简化运动学，推进器指向用于视觉表现。
